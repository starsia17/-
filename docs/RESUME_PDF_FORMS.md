# 이력서 구성과 회사 PDF 양식

마이페이지 → 이력서·프로필에서 이름, 생년월일, 직무, 이메일, 연락처, 개인 링크, 주소와 경력·활동 / 학력·교육 / 기술·사용 도구 / 수상·자격을 본문 위에서 작성합니다. 네 영역은 기존 서식 편집기를 사용합니다. 아래 본문은 자기소개와 입사 후 포부에 사용합니다. 기존 양식의 동일 제목 영역은 편집 화면에서 서식 그대로 분리되며 사용자가 저장하기 전까지 서버 원문을 변경하지 않습니다.

회사 지정 PDF 양식은 ‘PDF 양식 불러오기’로 본인 계정에 보관합니다. 입력 칸이 있는 PDF는 칸을 선택해 작성하고, 일반·스캔 PDF는 ‘글자 추가’ 후 원하는 위치를 눌러 작성합니다. 추가 글자를 끌어 옮기고 크기를 바꿀 수 있습니다. 프로필 항목은 선택한 칸에 명시적으로 가져옵니다. ‘새 작성본 저장’은 원본을 유지하고 작성본을 추가합니다. 작성본을 다시 열면 입력 내용을 이어서 수정할 수 있습니다. 원본과 연결된 작성본을 먼저 삭제해야 원본을 삭제할 수 있습니다.

파일당 20MB, 원본·작성본 합계 10개, 200페이지, 입력 칸 400개, 추가 글자 상자 100개를 지원합니다. 암호 보호·XFA PDF는 일반 PDF로 변환해야 합니다. PDF의 원래 서식을 편집하는 기능은 아니며 서명 인증이나 OCR은 제공하지 않습니다. 글자 상자 폭과 페이지 밖으로 넘치는 긴 내용은 사용자가 출력 전 확인해야 합니다.

PDF 원본·작성본·편집 상태는 소유자 인증을 거친 전용 경로에서만 제공하며 공개 포트폴리오 DTO나 공유 링크에 자동 포함하지 않습니다. 포트폴리오에 명시적으로 포함한 프로필은 생년월일·주소도 출력될 수 있습니다. 로그아웃·계정 전환 시 편집 창, 파일 목록, 다운로드 URL을 정리합니다. 기존 첨부 크기 50MB×10개, 업로드 동시 제한, 로그인·2단계 인증·CSP는 유지합니다. PDF worker에만 WebAssembly 실행을 허용합니다. 업로드 파일은 서버에서 PDF 서명과 크기를 확인하고 PDF 해석·편집은 브라우저에서 수행합니다. 참조 중인 회사 PDF는 기존 30일 고아 파일 정리 대상에서 제외합니다.

PDF 도구는 pdf-lib, fontkit, PDF.js를 npm에서 고정 잠금 파일로 설치하고 같은 사이트에서 제공합니다. 한글 출력에 사용한 Noto Sans KR의 SIL Open Font License는 `/vendor/resume-korean-license.txt`에서 제공합니다. 외부 AI API는 사용하지 않습니다.

검증은 운영 DB와 분리한 메모리 모델 및 Chromium에서 수행합니다. `node test-career.cjs`, fixture `node test-career.cjs --serve`, `node test-career-pdf.cjs`, `PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node test-career-browser.cjs`를 사용합니다. 다른 포트를 쓰려면 세 명령에 `CAREER_FIXTURE_PORT`를 동일하게 설정합니다. PDF 테스트는 PC 1440px·모바일 390px, 한글 PDF 텍스트 추출, 입력 칸/체크/선택, 빈 PDF 자유 입력, 저장·재편집, 원본 보존, 다른 계정 접근 거부, 다운로드, 계정 정리와 기존 양식 분리를 검증합니다. 실제 iOS/Android 기기의 다운로드 처리와 모든 외부 회사 PDF 형식은 별도 실제 기기 확인 범위입니다.
