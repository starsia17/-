# 본인 계정 회원탈퇴

마이페이지 → 내 정보 가장 아래에 회원탈퇴 버튼을 제공합니다. ‘정말로 회원을 탈퇴하시겠습니까?’ 창에서 ‘아니오’ 또는 Escape는 창만 닫고, ‘예’는 로그인한 본인 계정의 영구 삭제를 요청합니다. 기본 포커스는 ‘아니오’입니다. PC·모바일에서 확인창과 터치 버튼을 제공하며 계정 전환 시 확인창을 폐기합니다.

DELETE `/api/account`는 인증된 세션의 사용자 ID만 사용하고 `{confirmed:true}` 외의 본문 입력을 거부합니다. URL이나 본문에 다른 사용자를 지정하는 기능은 없습니다. 기존 Origin/CSRF, HttpOnly 세션·탭 인증, 등록 계정의 MFA 정책을 유지합니다. 계정에 탈퇴 표시와 인증 버전 증가를 원자적으로 기록하고 본인 세션·공유를 해제합니다. 탈퇴 중인 계정은 로그인·비공개 API·공개 공유를 차단합니다.

작성 중이던 저장/업로드가 탈퇴 후 자료를 다시 만드는 것을 막기 위해 모든 인증된 변경 요청과 로그인 발급에 본인 쓰기 작업을 기록합니다. MongoDB의 원자적 쓰기 임대와 로컬 카운터를 함께 사용합니다. 응답 연결이 끊겨도 실행 중인 처리 함수가 끝날 때까지 임대를 유지하며 다른 서비스 프로세스의 임대도 확인합니다. 서버가 종료되어 반환하지 못한 임대는 30분 후 만료됩니다. 정상 처리 후에는 임대를 즉시 제거합니다. 탈퇴 확정 후 새 임대를 만들 수 없습니다.

본인 게시글(휴지통 포함), 그 게시글의 파일, 이력서/프로필과 회사 PDF 원본·작성본, 포트폴리오(휴지통 포함), 공유 토큰, 본인이 작성한 뉴스·공지, 모든 본인 세션과 계정 문서를 삭제합니다. 파일 ID는 삭제 전에 계정 문서에 저장해 DB 또는 GridFS 오류 후 재시도할 수 있게 합니다. 파일은 다른 회원의 게시글·프로필 PDF·삭제 대기 파일 참조 및 GridFS 소유자 메타데이터를 추가 확인해 다른 계정 파일을 보존합니다. GridFS chunks와 files를 순서대로 삭제하고 모두 성공한 뒤 계정 문서를 삭제합니다. 오래된 고아 파일에 남아 있는 확인 불가능한 소유자를 임의로 추정해 타 회원 파일을 삭제하지 않습니다.

보통 요청 완료 시 HTTP 200과 삭제 완료 안내를 반환합니다. 진행 중인 처리 또는 연결 문제로 정리를 완료하지 못하면 HTTP 202와 접수/정리 대기 안내를 표시하며 즉시 로그아웃합니다. 정리 대기 계정은 새 로그인과 공유를 차단한 상태에서 서버 시작 시 및 매분 재시도합니다. 실패한 파일을 삭제됐다고 보고하지 않습니다. 완료 전 삭제 대상의 최소 상태를 유지하며 최종 완료 후 계정 문서도 삭제합니다. 지연된 응답이 같은 브라우저에서 새로 로그인한 다른 계정의 쿠키를 덮지 않도록 탈퇴 응답에서 쿠키를 덮어쓰지 않습니다. 기존 토큰은 서버에서 무효화됩니다.

관리자가 명시적으로 탈퇴하는 경우에도 본인 자료만 삭제합니다. 재시작 시 관리자 계정이 다시 만들어지는 것을 막기 위해 `portfolioSettings`에 계정 ID·비밀번호 등 개인정보가 없는 `admin-withdrawn` 비활성 표시만 유지합니다. 관리자 로그인도 중지된다는 점을 확인창에 표시합니다. 일반 회원의 탈퇴는 관리자나 다른 회원의 설정을 변경하지 않습니다. 이후 운영자가 새 관리자 구성을 의도적으로 복구하려면 이 비활성 설정부터 검토해야 합니다.

검증: `node test-withdrawal.cjs`는 격리된 모델/파일 저장소로 확인·CSRF·MFA 세션, 소유자 분리, 다른 회원 자료 보존, 연결 중단된 저장과 탈퇴 경합, 다른 프로세스 쓰기 임대, 로그인 차단, 공유 차단, 파일 삭제 실패 재시도, 관리자 재생성 방지, GridFS 범위와 Mongoose 필터를 확인합니다. `node test-withdrawal.cjs --serve`와 `node test-withdrawal-browser.cjs`는 PC 1440px/모바일 390px에서 버튼 위치, 취소 무변경, 계정 전환, 삭제 완료·로그아웃·로그인 거부를 확인합니다. 두 명령의 `WITHDRAWAL_FIXTURE_PORT`로 별도 포트를 사용할 수 있습니다. 운영 회원을 실제로 탈퇴시키는 검증은 수행하지 않습니다.
