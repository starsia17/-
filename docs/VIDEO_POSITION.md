# 외부 동영상 위치 변경

게시글 작성·상세 본문 편집에서 외부 동영상 링크를 넣으면 독립된 영상 블록으로 저장됩니다. 문장 사이에 삽입할 때 앞·뒤의 글과 서식을 보존합니다.

영상이 있는 편집 영역의 ‘이동할 외부 동영상’ 메뉴에서 대상을 선택한 뒤 ‘동영상 위로 이동’, ‘동영상 아래로 이동’으로 문단을 넘겨 배치합니다. 왼쪽·가운데·오른쪽 정렬도 영상별로 적용합니다. PC와 모바일에서 같은 버튼을 사용할 수 있습니다. 모바일처럼 영상이 화면 너비를 채우는 경우 좌우 정렬 차이가 작을 수 있습니다.

기존 본문의 YouTube/Vimeo 및 HTTPS 직접 동영상 링크도 위치 변경 대상입니다. 예전 인라인 링크를 이동하거나 정렬하면 앞·뒤 글을 보존하며 독립 블록으로 변환합니다. 지원되지 않는 영상 제공자는 원본 링크로 표시하고, 새로 삽입한 링크 블록의 위치는 변경할 수 있습니다.

배치와 정렬은 본문 HTML에 저장하며 상세 화면·포트폴리오·공유 미리보기·공개 공유에서 유지합니다. 편집 버튼은 저장 HTML에 포함되지 않습니다. 서버는 지정된 블록 표시와 기존 허용 정렬만 보존하며 임의 iframe·스크립트 입력을 허용하지 않습니다.

검증: `test-video-position.cjs`의 PC 1440px·모바일 390px 삽입/복수 영상/이동/정렬/정화 후 재로드/예전 링크/공유 렌더링 검사, `test-private.cjs` 실제 HTTP POST·PUT·GET 저장 보존 검사. 기존 보안 검사와 PDF·프로필·포트폴리오·공유 브라우저 검사를 함께 실행합니다.

추가 인증 강화: 2단계 인증 등록 계정은 회원·관리자 로그인 모두 인증 앱 코드 또는 미사용 복구 코드 검증 후에만 세션을 발급합니다. 로그인 유지 옵션은 이를 우회하지 않습니다. 등록 계정의 세션에는 2차 인증 검증 표시가 필요하며 표시가 없는 이전 세션은 다시 로그인해야 합니다. 미등록 계정은 기존 비밀번호 로그인으로 이용합니다.
