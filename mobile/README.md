# 포트폴리브 모바일 앱 1.0.0

Android는 운영 HTTPS 사이트를 사용하는 네이티브 WebView 앱입니다. 웹과 같은 서버·계정·자료를 이용합니다. 웹 화면 저장은 서버에 반영되며 다른 기기의 열린 화면에는 새로 불러올 때 표시됩니다. 다른 기기에 자동 푸시되는 실시간 편집 동기화는 이번 앱에 포함하지 않았습니다. 인터넷 연결이 필요합니다.

Android: APK를 내려받아 설치하세요. Android 8.0 이상, 최신 Android System WebView가 필요합니다. APK 설치 시 기기에서 해당 다운로드 앱의 ‘출처를 알 수 없는 앱 설치’를 허용해야 합니다. 파일 선택과 PDF 파일 저장 위치 선택은 Android 시스템 화면을 사용합니다. 인쇄용 창에서는 상단 ‘PDF 저장 · 인쇄’를 누르세요. 외부 링크는 외부 앱에서 엽니다. 비밀번호·MongoDB 접속 정보·관리자 키는 앱에 넣지 않았습니다. 웹사이트의 2단계 인증과 회원별 권한을 그대로 적용합니다. 웹브라우저와 앱 로그인 세션은 별개입니다.

iPhone은 APK를 설치할 수 없습니다. `ios`는 iOS 15 이상용 Swift/WKWebView 프로젝트 소스입니다. Mac에서 Xcode와 XcodeGen을 설치하고 `cd ios && xcodegen generate`로 프로젝트를 만듭니다. Xcode에서 Signing & Capabilities의 Apple 개발 팀을 선택하고 실기기에 빌드하거나 Archive → Distribute App으로 IPA/TestFlight를 생성합니다. App Store/TestFlight 배포에는 Apple Developer 등록 및 Apple 심사가 필요합니다. 이 환경은 Linux이므로 iOS 빌드·서명·실기기 검증을 수행하지 않았습니다. 앱스토어 등록을 완료한 상태가 아닙니다.

검증 범위: Android 컴파일·APK 서명·패키지 권한 검사는 수행합니다. Android/iPhone 실제 기기의 파일 선택·동영상·PDF·로그인 동작은 실기기 검증 전입니다. 서명 키는 소스에 포함하지 않고 별도로 안전하게 보관해야 동일 앱 업데이트를 설치할 수 있습니다. 기존 웹사이트 코드는 변경하지 않습니다.

## 1.1.0 앱 전용 업데이트

웹사이트 원본 및 운영 main은 변경하지 않았습니다. 사이트 로고의 A 심벌·색상·도형을 그대로 사용하는 Android 적응형 아이콘과 iOS AppIcon을 적용했습니다. 앱에서만 둥근 카드·일관된 입력칸·하단 메뉴·더보기 화면을 제공합니다.

앱 복귀 시 웹 화면을 새로고침하지 않고 유지합니다. Android는 1초 간격 및 백그라운드 전환 시 마지막 경로, 스크롤, 서식 본문, 이력서 초안, 포트폴리오 선택 순서·설명·생성 키, 작성 중 PDF 필드·글자 위치를 체크포인트로 기록합니다. 프로세스 종료 후에는 같은 계정의 서버 인증을 확인한 다음 복원합니다. 초안은 Android Keystore AES-GCM으로 암호화하며 백업에서 제외합니다. 첨부 초안 파일은 앱 전용 WebView IndexedDB에 보관하고 같은 계정의 파일만 복원합니다. 명시적 로그아웃·회원탈퇴·다른 계정 전환 시 초안을 정리합니다. 비밀번호·인증 앱 코드·복구 코드는 저장하지 않습니다. 30분 인증 만료 및 MFA 정책은 우회하지 않으며 재로그인 후 같은 계정 초안을 복원합니다. 7일을 넘긴 체크포인트는 자동 복원하지 않습니다.

브라우저 기반 앱 상태 검증에서 새 실행의 이력서 본문·서식, 프로젝트 선택/순서/설명, 생성 키, 계정 전환 및 만료 화면 보호를 확인했습니다. 실제 프로세스를 종료하고 같은 브라우저 저장소를 다시 연 테스트에서 첨부 파일 바이트와 본문 위치, PDF 초안을 확인했습니다. Android 코드 재컴파일·APK 서명 검증을 수행합니다. Android 실기기와 iOS 빌드·실기기 검증은 아직 하지 않았습니다. iOS 소스는 Keychain/CryptoKit 상태 보관 및 WebKit 문서 시작 주입을 추가했으며 Android와 다른 공개 API/DOM 어댑터를 사용하므로 동일한 기기 검증 완료 상태로 보지 마세요.

서버에 자동 저장·자동 재업로드하지 않습니다. OS가 앱을 즉시 강제 종료하거나 저장 공간이 부족하면 마지막 체크포인트 이후 작업·진행 중인 네트워크 전송은 완료를 보장할 수 없습니다. 복원된 초안을 확인하고 서버 저장 버튼으로 확정하세요. 기존 앱에서 작성 중인 내용은 저장한 뒤 APK를 업데이트하세요. 기존 1.0.0과 같은 서명 키·패키지를 사용합니다.
